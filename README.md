# Tanmay Sharma — Portfolio

Personal portfolio website showcasing my projects, skills, experience, and achievements.

Built with React, Vite, and TailwindCSS.

## Live

[tanmay-portfolio.vercel.app](https://tanmay-portfolio.vercel.app)

## Tech Stack

- React 19 + Vite
- TailwindCSS v4
- Lucide Icons
- Web3Forms (contact form)
- Vercel (deployment)

## Run Locally

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub and connect the repo to [Vercel](https://vercel.com). It auto-detects Vite and deploys.
